# Vault Station HQ

Public site for **Vaulted Labs** / **@VaultStationHQ**.

Live URL after Pages is on: https://vaultedlabs.github.io/

## Stack
Static HTML/CSS/JS. No build step.

## After $HOLDV launches
Edit `config.js` and set `ca` to the official mint. The copy button switches automatically.

## GitHub Pages
1. Repo: `VaultedLabs/VaultedLabs.github.io`
2. Settings → Pages → Source: **Deploy from a branch**
3. Branch: `main` / root
4. Save. First publish can take a minute.
